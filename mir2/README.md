# 传奇挂机小游戏（mir2）

纯前端挂机游戏：战士 / 法师 / 道士三人组自动打怪、拾取、换装、升级，无需操作。

本地运行（仓库根目录）：

```bash
npm run dev
# 访问 http://localhost:3000/mir2/
```

测试（本目录）：

```bash
npm test       # 45 个用例
npm run coverage  # 行覆盖率 100%，分支 92%+
```

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 页面骨架 + 样式，加载 `js/app.js` |
| `js/game.js` | 纯逻辑层（无 DOM）：战斗、技能、掉落、换装、升级 |
| `js/app.js` | DOM 胶水层：渲染、存档、主循环、事件绑定 |
| `test/game.test.mjs` | 单元测试（node:test，无第三方依赖） |
| `data/*.json` | 等级经验、物品、技能、怪物数值表，另有 `elites.json`（16 精英）、`bosses.json`（17 BOSS） |
| `data/drops.json` | 怪物掉落表（名称 → 掉落行数组），页面一次性载入 |

## 主体逻辑

战斗循环（`attack`，1 秒 1 次，速度滑杆 1–100 倍批量执行）：

1. 无目标时 `pickMonster` 选怪：`Lvl ≤ 等级+3` 的池子里，取当前最大伤害 25 倍血量内最强的（前 3 名随机），保证 1x 速度下 30 秒内杀一只；每次遭遇另有 1% 概率改出精英（`elites.json`，只看杀不杀得死、不看等级，弱精英低级也能撞大运，杀不动才回落普通怪）
2. `calcDamage` 结算：战士普攻吃攻击并乘技能倍率；法师 `魔法随机 + 技能 Power 随机` 吃魔御；道士火符另加施毒 / 骷髅 / 神兽固定加成；扣怪物 AC/MAC 随机减伤，保底 1 点
3. 击杀后 `gainExp` 按 `levels.json` 连升多级；`rollDrops` 对掉落表每行独立掷骰（`分子/分母` 即概率，`10/10` 必掉、`10/5000` 即 0.2%），命中后行末数字为数量（默认 1），重复行分别判定并累加，金币累加、物品进共享背包

技能（`bestSkill`）：按 `magics.json` 的 NeedL1/L2/L3 自动学会并升到 Lv.3，每次攻击实时计算期望伤害选最高的（战士烈火 > 半月 > 刺杀 > 攻杀 > 基本；法师雷电术等 9 个输出技能；道士灵魂火符）。

自动换装（`tryEquip` / `rebalanceEquips`）：8 通用槽（武器 / 衣服 / 头盔 / 项链 / 手镯×2 / 戒指×2），`StdMode` 映射槽位。装备属性是区间（`Dc/Mc/Sc/Ac/Mac` 为下限、`XxxMax` 为上限），只看本职业主属性上下限之和（战士攻击、法师魔法、道士道术）；防御不参与打分（模拟里角色不挨打），同分按 `NeedLevel` 高者优先，`NeedLevel` 不够不穿，分高才换，仅本职业有收益（分数 >0）的装备才穿。背包只计数，但穿戴占用数量：同一件装备全队穿着总数不超过背包数量（一枚戒指只能占一个槽，两槽位戒指 / 手镯要两份，跨角色同理）；掉落按收益最高的角色优先分配，升级 / 加载 / 每 5 秒会按背包数量全局重算最优分配。

装备品质（`itemQuality`）：按 `NeedLevel` 白（<16）绿（16–20）蓝（21–25）紫（≥26），四档数量约各 30、分布均匀；每个职业、每个部位（武器 / 衣服 / 头盔 / 项链 / 手镯 / 戒指）最强的那件为橙（属性并列则同橙，共 21 件）。凑齐每个部位的最强装备并备够两槽位数量，即可全橙，装备栏与背包名同色，悬停提示框内装备名同样着色。

存档：localStorage（`mir2-save-v1`）5 秒自动存，支持导出 / 导入文本、重置。

## 怪物池三分

`setDB` 按名把 `monsters.json`（163 去重）切成三池：`bosses.json` 17 只（教主 / 魔王 / 恶魔 / 树妖系）、`elites.json` 20 只（白野猪 / 触龙神 / 石墓尸王等小 BOSS，含 4 只掉橙普通怪升格）、普通池 136 只（掉橙装的 20 只已移出）。10 只水货测试怪（鸡1、沃玛教主1 等数字后缀错乱怪）直接丢弃。击杀统计分普通 / 精英 / BOSS 三类记在角色卡上。

## 首领挑战

三人 35 级后点"挑战首领"：打开挑战页面挂机暂停，关闭恢复。三人集火同一只（吃 100x 加速）。列表前 5 只（只掉紫）35 级一起开放，后 12 只（掉橙）按等级、血量升序排、36 级起每级解锁 2 只，未解锁显示 `Lv.X 解锁`；BOSS 名字掉毕业橙装的显示橙色、其余紫色，悬停看该 BOSS 的装备掉落（按品质、使用等级降序，仅装备）。每只每小时可战一次、冷却独立且走游戏内时间（倍速下冷却同样加速流逝），冷却中按钮直接显示 `冷却 m:ss`。打完一只可立刻挑另一只。掉落表 `drops.json` 进页面一次性载入，每行独立判定。胜利弹掉落汇总（单次掷骰，金币 / 物品进共享包，每人拿全额经验，三人首领击杀+1）。

## 金币买倍速 / 掉率

倍速上限初始 ×1，用金币逐档解锁：`2 / 3 / 5 / 8 / 12 / 20 / 35 / 60 / 100 / 160 / 250 / 380 / 500`，价格 `SPEED_COST`，买满累计约 3476 万；仿真下 1→40 级约 60 分钟、买满 500x。解锁后滑杆上限即当前档位，购买成功把当前速度直接拉到新上限；`speedMax` 存档。

首领掉率加成（`BOOST_TIERS` / `BOOST_COST`）：挑战前在列表顶部选档 `无 / ×2 / ×3 / ×5 / ×10 / ×20 / ×50`（5k / 15k / 40k / 100k / 250k / 100万），档位按等级开放（`boostUnlockLevel`：×2 要 35 级，每级开一档，×50 要 40 级，未开放显示 `Lv.X`）；挑战按所选档位扣费，金币不足或等级不够则提示、不自动降档；对掉落表每行概率乘倍率（封顶 100%），只作用于该次挑战；`boost` 存档。

## 有意简化掉的

- 怪物不反击，角色无血条不会死
- 不区分男女衣服
- 鸡肉 / 药水等消耗品只计数，不加属性
