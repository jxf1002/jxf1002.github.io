# 扑克牌素材

本目录的牌面 SVG 来自 [hayeah/playing-cards-assets](https://github.com/hayeah/playing-cards-assets)，
按 MIT 许可使用（见 `LICENSE-faces.txt`）。所有牌面均使用原始图，下载后用 SVGO 去除编辑器和冗余
元数据，画面本身未改。

牌背 `back.svg` 来自 [DeveloppeurPascal/SVG-cards](https://github.com/DeveloppeurPascal/SVG-cards)
（David Bellot 的 SVG-cards 2.0.1），按 LGPL 2.1 使用（见 `LICENSE-back.txt`）。

文件命名：`s` 黑桃、`h` 红桃、`d` 方块、`c` 梅花，数字 1-13 对应 A、2-10、J、Q、K，
例如 `s1.svg` 是黑桃 A，`c13.svg` 是梅花 K。
